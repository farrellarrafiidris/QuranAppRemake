# QuranAppRemake

QuranAppRemake is a web application designed to provide an easy-to-use interface for reading and understanding the Quran. The app features a simple and clean design, with functionalities to help users navigate through different Surahs and Ayahs of the Quran.

## Features

- **Surah and Ayah Navigation**: Allows users to easily navigate through different Surahs and Ayahs of the Quran.
- **Responsive Design**: The app is fully responsive, ensuring an optimal user experience on all devices, whether mobile or desktop.
- **Search Functionality**: Users can search for specific Surahs or Ayahs quickly.
- **Translation and Tafsir**: Provides translation and tafsir (interpretation) to help users understand the meaning of the verses.
- **Dark Mode**: Supports a dark mode to reduce eye strain, especially during night-time reading.
